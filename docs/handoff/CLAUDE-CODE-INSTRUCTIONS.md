## סשן 0 — הכנה חד-פעמית

הכנס את תיקיית `handoff/` לריפו תחת `docs/handoff/`, ואז הדבק:

```
קרא את הקבצים הבאים במלואם לפני כל דבר אחר:
1. docs/handoff/effie-claude-code-prompt.md — המפרט המחייב של כל המסכים
2. docs/handoff/effie-supabase-sync-map.md — מיפוי מסך→טבלה + 5 החוסרים בסכימה
3. docs/handoff/schema/*.sql — הסכימה הקיימת (אל תשנה טבלאות קיימות)

עכשיו צור/עדכן CLAUDE.md בשורש הריפו עם:
- ⚠️ מצב השקה — WHITE-LABEL בלבד: המותג "אֶפִי" עדיין לא נחשף. בכל מקום שהמפרט אומר "אפי" (כותרת עליונה, מסך כניסה, לוגו) — מציגים בשלב זה את שם המשרד מ-offices.name ("רימקס פמילי") ואת הלוגו מ-offices.settings.logo_url (קובץ הלוגו הקיים של המשרד). מימוש: קבוע BRAND_REVEAL=false בקונפיג; כשנחליף ל-true — המותג אפי (שם + לוגו אוריגמי docs/handoff/effie-logo.svg) מופיע בכל מקום. חריגים שנשארים גם עכשיו: "אפי סיכם" בסיכומי AI ומסך הצ'אט מקבלים ניסוח ניטרלי — "סיכום חכם" / "העוזר החכם".
- שם המוצר (לאחר החשיפה): אֶפִי (בלי דגש בפ׳). שם המשרד מגיע מ-offices.name — לעולם לא hardcoded.
- צבעים: קרם #F2EFE7, נייבי #1E3A5F, כחול פעולה #2E6BD6, זהב #C29435/#E4C56B, ירוק וואטסאפ #1FAF5E, אדום #C24040 (מחיקה בלבד).
- פונט Heebo. RTL. כרטיסים לבנים radius 20-22, צל 0 6px 20px rgba(30,58,95,.06).
- היררכיית כפתורים: כחול=ראשי, זהב=הדגשה/AI, ירוק=וואטסאפ/טלפון, לבן+מסגרת=משני, אדום=מחיקה (אייקון בלבד).
- ניווט תחתון, מימין לשמאל: שיחות · קונים · בית (אריח נייבי מורם במרכז) · חתימות · נכס נולד (לוגו אוריגמי + מונה).
- מחירים/תאריכים נשמרים כטקסט גולמי — הפורמט (₪, פסיקים) בצד לקוח בלבד.
- כתיבה ל-DB דרך השרת בלבד (service_role); קליינט = קריאה + Realtime.
- כל החלטה חדשה שאתה מקבל — הוסף ל-CLAUDE.md מיד.
אל תבנה שום מסך עדיין. תגיד לי מה הבנת ומה חסר.
```
