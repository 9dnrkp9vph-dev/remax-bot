# 5. מסכים (המפרט המלא עוצב ואושר)

1. **בית (דשבורד):** ברכה לפי שעה + תאריך, 3 כרטיסי סטטיסטיקה (שיחות/חתימות/קונים חדשים), פס "בריף הבוקר" (נייבי כהה + CTA זהב; אחרי צפייה — "צפה שוב" + תקציר), 4 פעולות מהירות (הוסף קונה, החתם, חיפוש נכס, תהליכים ועסקאות), פס "הנכסים שלי" (מודעות הסוכן המחובר: מונה פעילים + בלעדיות + מסתיימות החודש, כפתור "הצג" לרשימה המסוננת שלו בטאב נכסים), רשימת "דורש טיפול".
    **הרשאות תצוגה לפי תפקיד (חל על כל האפליקציה):** מנהל — כל המשרד · מתאמת — הסוכנים שמשויכים אליה · סוכן — רק הדאטה שלו. ממומש ב-RLS עם טבלת `agents` (עמודת `role`: manager/coordinator/agent + `coordinator_id` לשיוך סוכן←מתאמת).
2. **שיחות:** משפך `שיחות ← נענו ← הפכו לקונים`, מספר וירטואלי, פילטרים: הכל / נענו / לא נענו / חמים (לא "לידים" — מונח לא מוכר לסוכנים). כרטיס שיחה: נענתה (ירוק)/לא נענתה (אדום), משך שיחה, בלוק "אפי סיכם" עם לוגו קטן, פעולה ראשית לפי מצב ("+ הוסף כקונה" / "שלח וואטסאפ" + "חייג חזרה"). "הוסף כקונה" זמין בכל שיחה — גם שלא נענתה (אייקון + כחול). אייקון לפתיחת תמלול מלא.
    **הסתרת שיחות (חשוב — כך הסוכנים מנקים את הרשימה):** אייקון עין-חצויה בכל כרטיס מסתיר את השיחה (soft-hide, עמודת `hidden_at` — לא מחיקה); בתחתית הרשימה שורה "שיחות שהוסתרו · N" עם "הצג" לצפייה ושחזור.
3. **קונים:** חיפוש + "+ קונה", פילטרים: פעילים/חמים/בהקפאה/סגרו. כרטיס: שם, טלפון, סוכן, צ'יפ תקציב+דרישות, בלוק "אפי סיכם", כפתור אחד "התאם נכסים · N" + אייקוני וואטסאפ/טלפון. קונה חם: מסגרת זהב + תג "חם" + שורת הפגישה הקרובה.
    **תוצאות "התאם נכסים":** מסך תוצאות עם מתג רשימה/מפה. ברשימה — קיבוץ לפי מקור: "המשרד שלנו" קודם (כרטיסים מלאים), אחריו שת"פ (מעומעם, שם משרד שותף (ללא עמלה — לא רלוונטי בשת"פ)). כל כרטיס עם אחוז התאמה של אפי (≥90% ירוק, אחרת זהב) ובכל תוצאה (משרד ושת"פ כאחד) שתי פעולות: ופעולות "שלח לקונה (וואטסאפ)" / "החתם מתעניין" (זהב — ניווט לטופס החתמת מתעניין עם הקונה והנכס ממולאים מראש). במפה — אותן תוצאות כקלאסטרים (נייבי=משרד, כחול=שת"פ) עם תגי אחוז-התאמה.
4. **חתימות:** שני מסלולים — "החתם בעל נכס" (זהב ראשי), "החתם מתעניין" (משני). סינון זמן. כרטיס: כתובת, חותם, סוכן, צ'יפ סוג (מוכר/בלעדיות), סטטוס נקודה (ממתין זהב/נחתם ירוק), פעולה: "שלח קישור בוואטסאפ" (ירוק) או "צפייה במסמך החתום".
5. **נכס נולד:** מונה חי (Realtime), צ'יפים של ותק בפרסום (חודש 1/2/3/4/5+) עם מונים, חיפוש, כרטיס נכס: כתובת, פרטים, מחיר בולט, צ'יפ "חדש היום", תקציר 2 שורות.
    **שורת בעל הנכס (חשוב):** רוב הנכסים מגיעים עם שם בעל הנכס + נייד (עולים אוטומטית, המזכירה מעדכנת יומית) — מוצגים בשורה ייעודית עם 3 פעולות: חייג (כחול) / וואטסאפ (ירוק) / צפייה במודעה (נייבי). צ'יפ "כבר פנו: <שם סוכן> · N פניות" ירוק — מוצג למנהל ולמתאמת (לגבי הסוכנים שלה); סוכן רגיל לא רואה מי פנה וכמה. סינון הותק (חודש 1 עד 7+) — שורת צ'יפים אחת נגללת אופקית (לא עטיפת שורות), צ'יפ פעיל בזהב עם מונה, שורת סיכום "חודש X · N נכסים" + רמז גלילה (fade בקצה). פעולות סטטוס: פגישה / פולו-אפ (זהב כשפעיל) / לא מעוניין / הערה + שורת סטטוס נוכחי.
6. **נכסים (מאוחד):** מתג משולש "המשרד שלנו (N) / שת"פ (N) / שלי (N)" — משרד ברירת מחדל בכחול מלא; נכסי שת"פ מעומעמים (רקע `#F7F5EE`, מסגרת מקווקוות, שם משרד שותף ללא עמלה). **שת"פ מאותה רשת** (למשל רימקס קריות כשהמשרד רימקס פמילי): שם המשרד מודגש בנייבי (bold, צבע #1E3A5F) — בלי תג נוסף. ההשוואה לפי עמודת `network` בטבלת offices. כרטיס משרד: "קונים מתאימים · N" (שידוך הפוך); כרטיס "הנכס שלי": מסגרת זהב + התראת סיום בלעדיות. קישור למפה.
7. **מפה:** Leaflet, חיפוש + פילטרים צפים (המשרד / שת"פ / נכס נולד), קלאסטרים בנייבי, פיני מחיר (הנבחר בזהב), כפתור "המיקום שלי" (FAB עגול, geolocation). כרטיס נכס נבחר צף מלמטה: כתובת, סוג+חד׳+קומה+מ״ר+סוכן, צ׳יפי מאפיינים (מעלית/חניה/מרפסת/ממ״ד), צ׳יפ "N ימים בשוק" (זהב), מחיר + מחיר למ״ר, CTA "לכרטיס הנכס".
8. **פגישות ופולו-אפ:** Sheet כמעט מלא (נפתח עד למעלה, ידית גרירה) — הניווט התחתון נשאר גלוי מתחתיו. שורת "מסונכרן עם יומן Google · החשבון שאיתו נכנסת" (סנכרון דו-כיווני עם חשבון ה-Google של ההתחברות), סינון היום/השבוע/הכל. פולו-אפ באיחור צף ראשון בכרטיס אדום. כל שורה עם חיוג (כחול) + וואטסאפ (ירוק) + עריכה (עיפרון אפור — שינוי מועד/הערה/מחיקה). פגישות בכחול, פולו-אפ בזהב, הושלם = וי ירוק + עמעום. כפתור "קבע פגישה או פולו-אפ" בתחתית.
9. **תהליכים ועסקאות:** חיפוש, "+ תהליך חדש" (כחול) / "+ עסקה" (משני), כרטיס: שם, תפקיד+כתובת, מחיר בולט, צ'יפ סטטוס, "נמכר ← עסקה" (זהב) / עריכה / פח.
    **טופס עסקה חדשה (Sheet מלא, 3 סקשנים ככרטיסים):** נפתח מ"נמכר ← עסקה" (ממולא מראש מהתהליך) או מ"+ עסקה" (ריק). ① פרטי הסגירה — מחיר מבוקש (מוצג מחוק line-through) מול מחיר מכירה* (זהב, מודגש), תאריך סגירה*, כתובת. ② סוכנים ועמלה — סוכן+מייצג, סוכן שני אופציונלי; עמלה מתחשבת אוטומטית (2% + מע"מ ממחיר המכירה) **עם כפתור עיפרון לעריכה ידנית של הסכום** (דורסת את החישוב). ③ עו"ד (אופציונלי) + צירוף חוזה חתום. CTA דביק "סגור עסקה" (זהב) / ביטול. אחרי סגירה — הכרטיס עובר ל"נסגרו" עם מסגרת ירוקה.
9ג. **ניהול (מפתח) — בעל המשרד בלבד:** ניהול צוות (רשימת חברים עם תפקיד נבחר מ-dropdown: סוכן/מתאמת/מנהל; מתאמת מקושרת לסוכנים שלה; הזמנה בהמתנה + "שלח שוב"), "הזמן סוכן" (הזמנה ב-SMS/מייל). הגדרות משרד: שם+לוגו (white-label), מספר וירטואלי + מתג תמלול, חיבור גיליון נכסים (Google Sheets, סטטוס סנכרון), מתג שת"פ (שיתוף נכסים הדדי).
9ד. **עדכונים למשרד:** לוח פנימי. הודעה נעוצה (מסגרת זהב, אייקון נעץ) עם אישורי קריאה ("אישרו N / טרם N"); עדכונים רגילים עם אווטאר+תפקיד+זמן; כתיבה — מנהל ומתאמת בלבד, סוכנים קוראים ומאשרים. Badge מונה בתפריט הצד.
9ב. **דוחות מנהל:** פילטר זמן (שבוע שעבר/השבוע/החודש/השנה), 8 KPI (שיחות, נענו+%, חתימות, בלעדיות, מודעות, עסקאות, פגישות, % פגישות שהתקיימו), כרטיס "המובילים במשרד" מאוחד עם צ'יפים (גיוס נכסים/החתמת קונים/עסקאות/שיחות) — מקום 1 בזהב עם פס התקדמות, "כל 10 המובילים" מרחיב. בצ'יפ "עסקאות": מתחת לדירוג שורת פילוח לפי צד — מוכר / קונה / משכיר / שוכר (מונים). "גיוס נכסים בשת"פ" — דירוג 57 משרדים, **שם המשרד** (officeName מטבלת offices — לא שם האפליקציה; אפי = האפליקציה) מודגש בזהב. "נכס נולד לפי ערים" — טבלה. ייצוא: שלח בוואטסאפ (ירוק) / דוח PDF (נייבי) / העתק טקסט — **כל ייצוא מפיק דוח מפורט מלא לפי פילטר הזמן שנבחר** (כל הטבלאות: KPI, מובילים בכל הקטגוריות, פילוח עסקאות לפי צד, שת"פ, נכס נולד לפי ערים). ה-PDF מעוצב עם לוגו המשרד. **גרסת סוכן ("הדוחות שלי"):** אותו מסך מסונן לנתוני הסוכן, בלי מובילים ובלי שת"פ. מתאמת: הסוכנים שלה בלבד.
9ג. **ניהול (מפתח) — לבעל המשרד בלבד:** כרטיס משרד (שם, לוגו, צבעים, מספר וירטואלי — בסיס ה-white-label), "הזמן חבר צוות בוואטסאפ" (הזמנה = הדרך היחידה להצטרף), רשימת צוות עם תפקיד (מנהל/מתאמת/סוכן) ושיוך סוכנים למתאמת, השהיית משתמש במתג (מושהה לא רואה נתונים), מתגי מדיניות: שיתוף קונים בין סוכנים, חיוב פולו-אפ לפני סגירת נכס נולד, "מי פנה" למנהלים בלבד.
9ד. **עדכונים למשרד:** לוח הודעות פנימי. מנהל+מתאמות מפרסמים, סוכנים קוראים. הודעה נעוצה (מסגרת זהב), "נקראה ע"י X מתוך Y" + "מי קרא?" למנהל בלבד, קישור לנכס בתוך הודעה, עדכוני מערכת אוטומטיים של אפי (מסגרת מקווקוות). מונה לא-נקראו בתפריט הצד. כותרת "עדכונים קודמים" + "ארכיון מלא" — למנהל גישה לכל היסטוריית העדכונים (לא רק האחרונים).
9ה. **עזרה / דיווח תקלה (מהקיים):** מודאל עם בורר סוג (תקלה/באג · הצעת ייעול · אחר) + שדה תיאור + "שלח" — נשלח ישירות במייל למנהל המערכת. לשמר את הזרימה הזו בקו של אפי (גיליון תחתון, כפתור שליחה כחול לפי היררכיית הכפתורים).
9ו. **יומן שימוש במערכת (מהקיים, למנהל בלבד):** פיד חי של פעולות אחרונות — מי עשה מה ומתי (למשל "חי אלבז · הנכסים שלי · 01:30", "כניסת בדיקה כסוכן"). כולל אינדיקטור "חי". זהו מסך נפרד מ"עדכונים למשרד" (לוח ההודעות 31b) — לא לאחד ביניהם. טבלה: activity_log(office_id, user, action, target, ts).
10. **תפריט צד (מגירה מימין):** פרופיל, תהליכים ועסקאות, שידוך חכם (תג "חדש"), אפי AI (תג "חדש"), נכסים במפה, סנכרון יומן Google (מתג), הגדרות, התנתקות (אדום), גרסה.
11. **בריף הבוקר (פיצ'ר הדגל) — עולה אוטומטית בפתיחת האפליקציה:** סטורי יומי — **4 כרטיסים** ברצף (כמו אינסטגרם סטורי, פסי התקדמות למעלה, טאפ ימין/שמאל לניווט, החלקה למטה לסגירה): ① קונים בלי שיבוץ ② פולו-אפים ופגישות של היום ③ נכסים חדשים שנולדו. רקע נייבי כהה `linear-gradient(165deg,#0E1D33,#1E3A5F,#2C4C77)`, הדגשות זהב, לוגו האפרוח למעלה, כרטיס אחרון עם CTA "בוא נתחיל את היום" שסוגר את הסטורי ונוחת על דשבורד טעון ומוכן.
    **התנהגות פתיחה (חשוב):**
    - **כרטיס 1/4 — פתיחה:** המסך הכהה עם הלוגו בטבעת זהב זוהרת, "בוקר טוב, <שם>", 3 מספרי טיזר (קונים חדשים / חתימות ממתינות / ביומן היום), CTA "בוא נתחיל ←" וקישור "דלג לדשבורד". אחריו: קונים (2/4) ← חתימות (3/4) ← היום שלך (4/4).
    - ה-splash עובר ישר לסטורי — לא לדשבורד. בזמן שהסטורי מוצג, הדשבורד וכל הדאטה נטענים **ברקע** (הסטורי הוא מסך הטעינה האפקטיבי — המשתמש אף פעם לא רואה ספינר).
    - נתוני הבריף עצמם קלים (מוכנים מראש ע"י ה-Edge Function של 8:00 ונשמרים בטבלת `daily_briefs`) — נטענים בשאילתה אחת מהירה, או מ-cache מקומי אם אין רשת.
    - מוצג **פעם אחת ביום** בכניסה הראשונה (נשמר `last_brief_seen` פר-משתמש); בכניסות הבאות באותו יום — ישר לדשבורד, והבריף נגיש מהפס בדשבורד.
    - דילוג: כפתור X או החלקה למטה בכל שלב — נוחתים על הדשבורד המוכן.
    - אם אין בריף (סוכן חדש/אין דאטה) — מדלגים ישר לדשבורד בלי מסך ריק.
12. **אפי AI (צ'אט):** שיחה חופשית עם העוזר על הדאטה של המשרד ("כמה שיחות היו השבוע?", "מי הקונים למשהו ב-1.5M?").
13. **דסקטופ (Web) — כיוון בלבד, לא מפרט סגור (המובייל הוא המקור):** אותו קו — סרגל צד מימין (בית פעיל נייבי, נכס נולד עם badge), בריף כבאנר רוחבי, סטטיסטיקות 4 בשורה, גריד שתי עמודות. טאבלט: סרגל מתכווץ לאייקונים. מובייל: ניווט תחתון.

**כניסה:** "המשך עם Google" ראשי (אותו חשבון = סנכרון יומן Google) + חלופת קוד ב-SMS (OTP). אין הרשמה פתוחה — הצטרפות בהזמנת מנהל.

#> ⚠️ **מצב השקה (עדכני):** המותג "אפי" לא נחשף עדיין. עד להחלטה אחרת — הכותרות, מסך הכניסה והלוגו מציגים את המשרד עצמו: "רימקס פמילי" + הלוגו הקיים של המשרד (offices.name / settings.logo_url). דגל BRAND_REVEAL=false. "אפי סיכם" → "סיכום חכם"; צ'אט אפי → "העוזר החכם". שאר המפרט ללא שינוי.

# 6. Supabase

- **RLS חובה** על הכל, מפתח `office_id` — הפרדה מלאה בין משרדים (בסיס ה-White-Label).
- טבלאות ליבה: `offices` (שם, לוגו, צבעים), `agents` (כולל `role`: manager/coordinator/agent + `coordinator_id`), `calls` (+ תמלול וסיכום AI), `buyers`, `properties` (מקור: משרד/שת"פ/נכס-נולד, ותק פרסום), `signatures` (קבצים ב-Storage), `deals`, `follow_ups`, `property_status_log`.

- **Storage:** מסמכים חתומים, לוגואים של משרדים.
