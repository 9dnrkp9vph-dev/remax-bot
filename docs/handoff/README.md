# חבילת Handoff — אֶפִי (Effie)

## מה יש כאן
- `effie-claude-code-prompt.md` — **המסמך המרכזי**: מפרט מלא של כל 13 המסכים, ההחלטות, ההרשאות, ה-Supabase. תן אותו ל-Claude Code כבריף.
- `effie-logo.svg` — הלוגו הווקטורי (אפרוח אוריגמי). צבעים: זהב #E4C56B / #C29435 / #EED9A0 / #D8AC4E, נייבי #1E3A5F.
- `app-icon-1024.png` — אייקון App Store (1024×1024, ללא שקיפות).
- `design/שיפור האפליקציה.dc.html` — קובץ העיצוב המלא. **פתח בדפדפן** (עם הקבצים שלצידו באותה תיקייה) כדי לראות את כל המסכים המאושרים. Claude Code יכול גם לקרוא את ה-HTML ישירות ולמשוך ערכים מדויקים (צבעים, ריווחים, גדלים).

## איך להתחיל ב-Claude Code
1. שים את התיקייה הזו בתוך ריפו האפליקציה (למשל `docs/handoff/`).
2. פתח את Claude Code והפנה אותו: "קרא את docs/handoff/effie-claude-code-prompt.md — זה הבריף. קובץ העיצוב ב-docs/handoff/design/ הוא מקור האמת הוויזואלי."
3. עבוד מסך-מסך לפי סדר המסמך (בריף הבוקר ← בית ← שיחות ← ...).

## סדר הסבבים בקובץ העיצוב
הגרסאות המאושרות הן תמיד ה**עליונות** בקנבס (סבב גבוה = עדכני). המעבר דף-דף (סבבים 13–27) הוא המפרט המחייב; סבבים 1–12 הם היסטוריית התהליך.
