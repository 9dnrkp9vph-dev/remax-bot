# תחרות קבוצות — תוכנית בנייה

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** תחרות קבוצות באפי. הניקוד נספר לבד מגיוסי בלעדיות ופגישות. התחרות מוצגת ככרטיס ראשון בסטורי, במסך `/v2/contest` ובטלוויזיה, ויש לה מסך הגדרה ותיקון ידני למנהל.

**Architecture:**
- מודול חדש `contest.py`, בדפוס של `goals.py` ו-`day_wa.py`:
  - פונקציות טהורות לחישוב.
  - `register(app, G)` לראוטים ולדפים.
  - `V2_CONTEST_KIT` — CSS ו-JS משותפים לכרטיס, מוזרקים לבית ולטלוויזיה.
- הנתונים נשמרים בקונפיג, דרך `_config_mutate`.
- בלי טבלה חדשה ובלי SQL.

**Tech Stack:** Python 3 / Flask, vanilla JS בתוך מחרוזות HTML, בדיקות `python3 tests/...` ו-`node tests/....js`. אלה דפוסי `tests/goals`.

**Spec:** `docs/superpowers/specs/2026-11-02-contest-design.md` (אושר ע"י אייל 02/11). דוגמת המסך המאושרת: `/Users/eyal/Documents/remax-family/docs/handoff/mockups/contest-november-mockup.html`.

- `validate(contest, canon) -> str|None` — הודעת שגיאה בעברית, או None. תופס:
  - שם שמופיע פעמיים בכל התחרות, כולל בין קבוצות ובין סוכנים למתאמות.
  - תאריכים לא תקינים, או end < start.
  - נקודות שליליות, או מעל 1000.
  - מספר קבוצות שאינו 2.
- `ledger_update(ledger: dict, nb: dict|None, contest, now: float, display) -> dict` — מחזיר ledger חדש ולא משנה את הקלט.
  - `nb` = `cfg["nbStatus"]`.
  - `display(by, by_phone) -> str` — מחזיר את שם המתאם.
  - פגישה נכנסת ל-ledger כש-`rec.status=="meeting"` ו-`parse_ts(rec.meeting_at)` בתוך התחרות. זה כולל גם מפתחות `manual:`.
  - שורת ledger: `{"agent", "by", "at": meeting_at ts, "when": ts של rec["date"] או None}`.
  - רשומה שכבר לא פגישה, או שנעלמה: נשארת אם `when` עבר (`when <= now`), ונמחקת אם `when` עוד לא הגיע.
  - `nb` שהוא `None` או חריגה → מחזיר את ה-ledger כמו שהוא.
- `listing_anchors(names, bounds, sigs, canon) -> set|None` — כמו `goals.count_listings`, אבל מחזיר את קבוצת העוגנים של כל השמות יחד. משתמש ב-`goals._anchor` ובכללי הסינון של `count_listings`.
- `score(contest, ledger, sigs, adjustments, canon, now) -> dict`:
  - `sigs` = רשימת `goals.g_sigs` מתחילת החודש הקודם, או `None`.
  - `adjustments` = רשימת `{"id","group","kind":"row"|"coord","label","pts","reason","by","at"}`.
  - המבנה שמוחזר:
    ```
    {"id","name","start","end","days_left","pts",
     "groups":[{"name","total","rows":[{"label","members","meetings","gius","adj","points","pd","rank"}],
                "coords":[{"name","meetings","adj","points"}]}],
     "leader": 0|1|None}
    ```
  - `None` = תיקו.
  - **ניקוד:**
    - `points = gius*pts.gius + meetings*pts.meeting + adj`.
    - `meetings` של שורה = מספר שורות ה-ledger שה-`agent` שלהן הוא אחד מחברי השורה.
    - `meetings` של מתאמת = שורות ledger שה-`by` שלהן הוא המתאמת, וה-`agent` שלהן הוא לא היא.
    - `gius` = גודל `listing_anchors` של החברים בתאריכי התחרות.
    - `pd` = גודל `listing_anchors` בחודש הקודם.
    - כש-`sigs` הוא None — גם `gius` וגם `pd` הם None. `points` מחושב מהשאר, ומסומן `"partial": True`.
  - **סדר ודירוג:** השורות ממוינות לפי `points` יורד, ו-`rank` מתחיל מ-1. `total` = סכום ה-`points` של השורות בלבד, בלי מתאמות.
  - **ימים שנשארו:** `days_left` = ימים קלנדריים מ-`now` עד `end`, כולל היום, ולא פחות מ-0.
