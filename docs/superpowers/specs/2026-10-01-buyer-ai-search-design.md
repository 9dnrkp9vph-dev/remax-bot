# חיפוש קונה AI — תכנון

תאריך: 01/10/2026 · בקשת אייל · מאושר בשיחה (ב/ב + "צא לדרך", והחלפת אריח הבית)

## המטרה

מקלידים תיאור נכס/דרישה ("דירת 4 חדרים באפקה 2.1 מיליון עם מעלית") ומקבלים את הקונים המתאימים — מהקונים השמורים ומהשיחות שנענו — ממוינים לפי התאמה, עם "למה מתאים".

## החלטות

| # | החלטה |
|---|-------|
| 1 | שני מקורות בשני טאבים: **"קונים שמורים"** ו-**"משיחות שנענו"** (מתקשרים שעוד לא קונים, עם "הוסף כקונה"). |
| 2 | סוכן מחפש בקונים של **כל המשרד**; על קונים של אחרים: שם פרטי, הסוכן המטפל, תקציב, מה מחפש — בלי טלפון/סיכום/פעולות חיוג; כפתור "וואטסאפ לסוכן המטפל". הקונים שלו — כרטיס מלא. מנהל — הכל במלואו. שיחות — כל סוכן רק את שלו (כמו היום). |
| 3 | אין "10 השיחות האחרונות" כשאין התאמה — מצב ריק. |
| 4 | אריח "חיפוש נכס" בבית מוחלף ב-**"חיפוש קונה AI"** (חיפוש נכס נגיש מ"נכסי המשרד"). |

## ארכיטקטורה

- **שרת — `POST /v2/api/buyers/ai_search {q}`** (effie_v2, ב-`register`): פירוק `G["_parse_props_query"](q)` (משותף ומוטמן); ניקוד טהור ברמת המודול:
  - `bai_budget(s) -> int` — תקציב מטקסט חופשי ("1,500,000" / "2 מיליון" / "1.5-2 מיליון" → הגבוה).
  - `bai_rooms(text) -> (lo, hi) | None` — חדרים מהטקסט ("4 חדרים", "3-4 חד'", "4.5 חד'").
  - `bai_score(parsed, text, budget, recent) -> (score 0-100, why[])`: אזור (שם עיר/שכונה/רחוב מהשאילתה בטקסט הקונה → 40; הקונה מזכיר עיר אחרת מהרשימה ולא את המבוקשת → 0 = לא מוצג; לא מזכיר עיר → 10; שאילתה בלי אזור → 20) · תקציב מול מחיר (מתחת ל-85% → 0; 85%-135% → 30; מעל → 12; חסר → 8) · חדרים (חפיפה → 20; סתירה → -20; לא ידוע → 6) · תכונות חובה שבטקסט (+3 כ"א, עד 10) · חדש (30 יום) +5. סף הצגה 40.
  - קונים: `_fetch_manual_buyers()` כולם; "שלי" לפי אותו סקופ של `/api/my/buyers` (`_scope_keys_phones`); מנהל = הכל שלו. סטטוס מ-`_bstat_load()` ('סגר' יורד לסוף). עד 40.
  - שיחות: אותו סקופ של `/api/search/buyers`; טקסט = `transcript_summary`, תקציב = `extract_budget_from_transcript`; בלי טלפונים שכבר קונים. עד 20.
- **קליינט — מסך הקונים:** Enter בחיפוש → `aiSearch()`; `render()` עם תוצאות → `renderAI()`: טאבים (`.mtabs`), שורת סיכום + "נקה חיפוש", כרטיס קונה רגיל (מחולץ ל-`buyerCardHtml(b, i, extra)` — פלט זהה ל-render הרגיל) עם אחוז התאמה ותגיות; כרטיס מצומצם לקונה של סוכן אחר; כרטיסי שיחה כמו היום.
- **בית:** האריח → "חיפוש קונה AI" (אייקון זהב = AI) → `/v2/buyers?ai=1` (פוקוס לשדה, placeholder של תיאור נכס).

## בדיקות

python על `bai_budget/bai_rooms/bai_score` + אינטגרציית הראוט (פרטיות: אין טלפון/סיכום לקונה של סוכן אחר; מנהל רואה הכל; עיר אחרת לא מוצגת; שיחה של קונה קיים לא מוצגת). node: `buyerCardHtml` זהה ל-render הקודם; `renderAI` טאבים/מצומצם/ריק. דפדפן.
