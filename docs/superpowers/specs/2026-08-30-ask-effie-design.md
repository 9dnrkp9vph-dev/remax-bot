# "שאל את אפי" — עוזר נתונים אישי (30/08/2026)

## החלטות אייל
משולב (אופציה ג'): כפתורים מהירים דטרמיניסטיים + שאלה חופשית ל-AI. השם "שאל את אפי" —
החלטה מודעת (המותג כבר נחשף ב-TV/SMS/App Store). **כלל ספירה: נחתם ולא נשלח** —
כל המונים סופרים רק חתימות שנחתמו בפועל (`commission_pct` מלא — אותו כלל כמו מסך
החתימות: קישור מסמך חתום/עמלה), וגיוסים נספרים לפי **נכס ייחודי** (עוגן-כתובת,
לא כל שליחה חוזרת), ושמות מנורמלים (`_canon_key` — מתקן "אלי  שמול").

## ארכיטקטורה
- **מסך `/v2/effie`** (V2_EFFIE_HTML): צ'אט RTL בפלטה (קרם/נייבי, זהב=AI). כניסה
  מכפתור בבית + פריט מגירה. צ'יפים מהירים לפי תפקיד; שדה חופשי; תשובות ככרטיסים.
- **`GET /v2/api/effie/card?q=<preset>&as=`** — תשובות מחושבות (בלי AI):
  `me` (המצב שלי/של סוכן — מנהל בלבד עם as) · `today` (פגישות+פולו-אפ+חתימות ממתינות) ·
  `hotbuyers` · `stuck` (ממתינות חתימה) · `trends` (4 שבועות מתגלגלים אישי) ·
  `office` + `officetrends` + `top` (מנהל). כרטיס = JSON מובנה (title/lines/insights),
  הקליינט מרנדר גנרית.
- **`POST /v2/api/effie/ask {q}`** — AI: בונה תמצית נתונים ממודרת לסקופ השואל
  (אותם אגרגטים), שולח ל-Claude (`claude-sonnet-4-5`, אותו API key קיים, timeout 30,
  max_tokens 700) עם הנחיות: לענות רק מהתמצית, בעברית, "אין לי נתון" עדיף על ניחוש.
  מכסה: 20 שאלות AI ליום למשתמש (מונה בזיכרון, מתאפס ברסטארט — מספיק v1).
- **הרשאות:** סוכן = הסקופ שלו בלבד (השרת אוכף, כמו כל המסכים); מנהל = משרד + as.
  מתאמת = כמו סוכן על הצוות שלה (הסקופ הקיים).

## חוקי החישוב (ef_* helpers, טהורים וברי-בדיקה)
- `ef_signed(g)` — commission_pct לא ריק.
- `ef_gius(sigs)` — בלעדיות חתומות בלבד, ייחוד לפי עוגן-כתובת (עד המספר הראשון).
- `ef_konim(sigs)` — החתמות קונים חתומות, ייחוד לפי (לקוח, עוגן-כתובת).
- דירוגים: קיבוץ לפי `_canon_key(agent)`.
- מגמות: חלונות מתגלגלים של 7 ימים ×4 (חתום-בלבד), קונים חדשים לפי date,
  עסקאות לפי close_date.
- רשומות בדיקה: שורות שכתובתן מכילה "בדיקה בדיקה" מוחרגות מהמונים.

## לא ב-v1
זיכרון שיחה, פעולות, גרפים, בחירת-סוכן יפה למנהל (v1: prompt שם). תיקון אותם
כללים בדוח הרגיל (/api/report) — משימה נפרדת ביומן.
