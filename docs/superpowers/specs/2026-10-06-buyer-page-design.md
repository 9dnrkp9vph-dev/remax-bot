# דף קונה עם התאמות נכסים — ספק

**תאריך:** 2026-10-06 · **מאשר:** אייל · **סטטוס:** אושר בשיחה, ממתין לסקירת הספק הכתוב

## רקע ומטרה
הסוכן שולח היום נכסים לקונה מחלון "התאמת נכסים" (מסך הקונים) כהודעת טקסט בוואטסאפ (`sendSelected`).
אין רישום מה נשלח, ואין משוב מהלקוח. בהשראת דף Webot/מדלן (סרטון של אלמוג וייל) — **דף אישי ללקוח**:
קישור קבוע אחד לכל קונה, עם כל הנכסים שהסוכן בחר עבורו, שהלקוח מסמן עליהם מתאים / לא מתאים / רוצה לראות,
והסימונים חוזרים לסוכן. בנוסף — הסוכן מקבל עדכון על נכסים חדשים שמתאימים לקונה.

## 1. הדף ללקוח — `GET /b/<token>`
עמוד HTML מלא, RTL, Heebo, פלטת אפי, **מיתוג המשרד בלבד** (שם ולוגו מהקונפיג, בלי "אפי"/Powered by).

- **כותרת קבועה:** תמונת הסוכן עגולה (`/v2/api/avatar?p=`, נפילה לאות ראשונה) · שם הסוכן · שם המשרד · כפתור וואטסאפ (ירוק) + חיוג — לטלפון הסוכן.
- **פתיח:** "שלום [שם פרטי], הנכסים שבחרתי בשבילך" + צ'יפי "מה מחפש" (אזור, חדרים, תקציב — מ-`search`/`budget` של הקונה, ללא סיכום שיחה).
- **רשימה:** קודם הנכסים מהשליחה האחרונה (תג "חדש"), אחר כך לפי זמן השליחה יורד. "לא מתאים" יורדים לסקשן מקופל בתחתית "לא מתאימים (N)".
- **כרטיס (משרד/שת"פ/שלי):** קרוסלה (החלקה + חצים + מונה "3/11"; הקשה → מסך מלא), רחוב+שכונה+עיר, מחיר גדול (ירד מאז השליחה → ישן מחוק + חדש), חדרים · קומה · מ"ר, תיאור מקוצר + "קרא עוד", שלוש פעולות. נכס שירד מפרסום → "כבר לא זמין", בלי פעולות.
- **כרטיס נכס נולד:** בלי תמונה ובלי מספר בית; תג זהב "נכס חדש לפני פרסום · פרטים אצל [סוכן]"; אותן פעולות.
- **פעולות:** "מתאים" (כחול כשמסומן) · "לא מתאים" (נפתח שדה "למה? (לא חובה)", עד 200 תווים) · "רוצה לראות" (ירוק — `wa.me/<סוכן>?text=אשמח לתאם ביקור ב[כתובת ללא מספר בית לנכס נולד]` + mark=visit). לחיצה חוזרת על סימון פעיל מבטלת אותו.
- **פג תוקף / טוקן לא קיים:** מסך מעוצב — תמונת הסוכן (אם ידוע), "הרשימה כבר לא פעילה — דבר איתי", וואטסאפ + חיוג. טוקן לא קיים → בלי פרטי סוכן, רק "הקישור אינו פעיל".
- **בלי:** שיתוף, מיון, מונים, קישורים חיצוניים. `noindex`, בלי heartbeat של יומן השימוש.

## 2. הצד של הסוכן — מסך הקונים `/v2/buyers`
1. **שליחה מחלון "התאמת נכסים":** `sendSelected` → `POST /v2/api/bpage/send` → פותח `wa.me` מהטלפון של הסוכן (כמו היום) עם:
   - שליחה ראשונה: "היי [שם], הכנתי לך רשימת נכסים אישית: [קישור]"
   - הבאות: "היי [שם], הוספתי לך N נכסים חדשים: [קישור]"
   - נכס שכבר בדף מסומן בחלון "בדף הלקוח" / "בדף · מתאים" / "בדף · לא מתאים" (מטעינת `GET /v2/api/bpage`).
   - נכס נולד מקבל כפתור בחירה בחלון (נכנס כרטיס מוסתר). `sendOne` (שליחת נכס בודד) עובר אף הוא דרך הדף.
   - "החתם על N נכסים" — ללא שינוי.
2. **שורה בכרטיס הקונה** (`buyerCardHtml`): "דף לקוח · 2 מתאים · 1 רוצה לראות · 3 התאמות חדשות" — רק החלקים שאינם 0; נקודה כחולה כשיש סימון שנעשה אחרי `seen_at`. הנתונים מ-`/api/my/buyers` (שדה `bpage` מצורף לכל קונה עם דף).
3. **גיליון "דף הלקוח"**: נכסים מקובצים — רוצה לראות · מתאים · טרם סומן · לא מתאים — עם הערה וזמן סימון. פעולות: "פתח כמו שהלקוח רואה" (`/b/<token>?preview=1` — לא נספר כצפייה), "שלח שוב את הקישור", הסרת נכס (פח בריבוע `#FBEDED`), "התאמות חדשות (N)" → פותח את חלון ההתאמות עם תג "חדש" על הנכסים החדשים. פתיחת הגיליון → `POST /v2/api/bpage/seen`.
4. **פרטיות:** סוכן — רק קונים שלו; מתאמת — הסוכנים שלה; מנהל — הכל (אותה בדיקה כמו `/api/my/buyers`). פוש — לסוכן המטפל בלבד.

## 3. נתונים — SQL (אייל מריץ)
מיגרציה: `supabase/migrations/20261006_buyer_pages.sql` (בריפו remax-family, כמו שאר המיגרציות).
```sql
create table if not exists buyer_pages (
  id           uuid primary key default gen_random_uuid(),
  office_id    uuid not null references offices(id) on delete cascade,
  buyer_id     uuid not null references buyers(id) on delete cascade,
  token        text not null unique,
  agent_name   text not null default '',
  agent_phone  text not null default '',
  created_at   timestamptz not null default now(),
  last_sent_at timestamptz not null default now(),
  expires_at   timestamptz not null,
  seen_at      timestamptz,
  unique (office_id, buyer_id)
);
create table if not exists buyer_page_items (
  id         uuid primary key default gen_random_uuid(),
  page_id    uuid not null references buyer_pages(id) on delete cascade,
  source     text not null check (source in ('office','shtaf','newborn','mine')),
  prop_key   text not null,
  snapshot   jsonb not null default '{}'::jsonb,
  added_at   timestamptz not null default now(),
  mark       text check (mark in ('like','dislike','visit')),
  note       text not null default '',
  marked_at  timestamptz,
  unique (page_id, prop_key)
);
alter table buyer_pages enable row level security;       -- בלי policies: שרת בלבד
alter table buyer_page_items enable row level security;
```
- **`buyer_id` = uuid** של הקונה (לא `sheet_row`, שזז במחיקה ב-`buyers_delete_row`). השרת ממיר row→id בשליחה.
- **טוקן:** `secrets.token_urlsafe(16)` (22 תווים).
- **`prop_key`:** משרד/שלי — טוקן יד2 (אחרת מספר מודעה); שת"פ — `X:<token>`; נכס נולד — `N:<_nb_key>` (אותם מפתחות של מנגנון ירידות המחיר).
- **snapshot:** `{street, house, neighborhood, city, price, rooms, floor, sqm, type, desc, images[]}`. לנכס נולד: `house=''`, `images=[]`, ובלי טלפון/שם בעלים. לשת"פ: בלי `office`/`link`.

## 4. שרת
שכבת נתונים ב-`supabase_db.py` (`bpage_get_by_token`, `bpage_get_by_buyer`, `bpage_upsert`, `bpage_add_items`, `bpage_mark`, `bpage_remove_item`, `bpage_seen`, `bpage_active_pages`); ראוטים ב-`effie_v2.register`.

| נתיב | הרשאה | גוף / תשובה |
|---|---|---|
| `POST /v2/api/bpage/send` | סוכן (`_web_auth`) + בעלות על הקונה | `{row, items:[{source,key}]}` → `{ok, url, first, added, msg}` |
| `GET /v2/api/bpage?row=` | כנ"ל | `{ok, page:{url, expires, seen_at}, items:[…], new_matches:[…]}` |
| `POST /v2/api/bpage/remove` | כנ"ל | `{row, key}` |
| `POST /v2/api/bpage/seen` | כנ"ל | `{row}` |
| `GET /b/<token>` | ציבורי | HTML |
| `POST /b/<token>/mark` | ציבורי | `{key, mark: like|dislike|visit|null, note}` → `{ok}` |

- **הצילום נבנה בשרת** — הקליינט שולח רק `source`+`key`; השרת מאתר את הנכס במקורות הקיימים (`fetch_sheet_rows` / שת"פ / נכס נולד / הנכסים שלי). נכס שלא נמצא → נדחה (לא נכנס לדף). פונקציה טהורה `bpage_snapshot(source, row)` אוכפת את כללי החשיפה.
- **שליחה:** דף קיים → `last_sent_at=now`, `expires_at=now+90d`, נכסים קיימים לא מוכפלים (unique), תג "חדש" = `added_at` של השליחה האחרונה.
- **טעינת הדף הציבורי:** מעשיר כל פריט מול המקור החי — מחיר מעודכן (וישן מחוק אם ירד), `delisted` → "כבר לא זמין". פריט שלא נמצא במקור — מוצג מהצילום.
- **mark:** רק `key` שקיים בדף; `note` רק עם dislike, חיתוך 200; הגבלת קצב 30 לדקה לטוקן (בזיכרון); דף שפג → 410. רישום ב-activity ("סימון בדף לקוח"). לא נשמר IP/מזהה לקוח.
- **פוש לסוכן:** `send_push(title, body, [last9 של הסוכן])` ב-thread. "בתיה ברון: רוצה לראות — יששכר 4" / "סימנה 3 נכסים". איחוד: בתוך 10 דק' לאותו דף — פוש אחד מסכם (בזיכרון; restart = לכל היותר פוש נוסף). שעות שקט — לפי `send_push` הקיים.
- **התאמות חדשות:** פונקציה טהורה `bpage_new_matches(buyer, listings_by_source, sent_keys, since)` — מפרקת את דרישות הקונה כמו חלון ההתאמות (`_parse_props_query` על `search`+`budget`), מנקדת עם `score_match`, מחזירה רק חזקות שלא נשלחו ושנכנסו אחרי `since` (`_y2_first_seen` / נראה-לראשונה). רצה:
  - בבקשה — `GET /v2/api/bpage` ו-`/api/my/buyers` (מטמון 10 דק' לדף).
  - ברקע — thread יומי (בשעה 10:00, idempotent ביומן בקונפיג `v2_bpage_digest[יום]`): לכל דף פעיל — התאמות מ-24ש' האחרונות → פוש מסכם אחד לכל סוכן ("3 נכסים חדשים מתאימים ל-2 קונים שלך"). כיבוי: env `BPAGE_DIGEST=0`.
- **כיבוי כללי:** env `BPAGE=0` → `sendSelected` חוזר להתנהגות הישנה (טקסט).

## 5. תלות בסורק (בקשה לצ'אט הסורק)
`mapApiRow`/`itemImage` ב-`yad2_sync.user.js` שולחים גם `images: [...]` (המערך המלא — כבר קיים ב-JSON שנקרא, בלי בקשות נוספות ליד2). בצד שלנו: הנרמולים (`y2_norm_office`, `y2_norm_agency`) שומרים `raw['תמונות']` (רשימה). עד אז, ולנכסים שלא נסרקו מחדש — `images=[raw['תמונה']]`.

## 6. בדיקות (TDD)
- **Python** (חילוץ ast / `register` עם G מדומה / requests מזויף):
  `bpage_snapshot` — נכס נולד בלי מספר בית/תמונות/טלפון; שת"פ בלי משרד/קישור; משרד עם כל התמונות + נפילה לתמונה אחת ·
  send — יצירה, הוספה ללא כפילות, הארכת תוקף, נכס לא קיים נדחה, סוכן אחר → 403, row→uuid ·
  `/b/<token>` — אין טלפון של אחר ב-HTML, פג תוקף → מסך סגירה, טוקן לא קיים, מחיר חי/ירד מפרסום ·
  mark — תקין, ערך לא חוקי, מפתח לא בדף, הגבלת קצב, פוש לסוכן הנכון, איחוד 10 דק' ·
  `bpage_new_matches` — חזקות בלבד, בלי שנשלחו, `since`.
- **JS (node):** דף הלקוח — קרוסלה, קיפול "לא מתאים", הודעת "רוצה לראות", ביטול סימון; צד הסוכן — `sendSelected` החדש, שורת הכרטיס, הגיליון.
- **בכל קומיט:** `node --check` על כל סקריפט עמוד שנגעתי בו · `ast.parse` לקבצי Python · אין פונקציות בשם כפול · קשירת ראוטים לפונקציה הנכונה.
- **אחרי deploy:** חשבון הביקורת (סוכן) — שליחה מחלון ההתאמות, פתיחת הקישור בדפדפן נקי, סימון, הופעה בגיליון.
