# yad2 → אפליקציה: יציאה שנייה מהצינור (30/08/2026) — ספק ראשוני

## רקע
פרויקט ה-yad2 (צ'אט "הוראות המשך לפרויקט yad2"; `HANDOFF_NEXT.md` ב-
`~/Documents/yad2_pipeline_update/`): Tampermonkey בכרום עם login (לפטופ win-yahv; יד2
חוסם ענן/Radware) → Apps Script → גיליון ייעודי + דשבורד. שני זרמים: פרטיים (כל 8-30
דק', ~900 מודעות) ומשרדי תיווך (2×יום, ~1,700, כולל דגל בלעדי, טלפון, officeId).

## הארכיטקטורה שאושרה
הסריקה לא משתנה. ה-Apps Script של הפרויקט מוסיף **forward** (אחרי כל שמירה מוצלחת,
לא-חוסם, retry×2, מאחורי דגל APP_FORWARD כבוי עד תיאום) אל
`POST /v2/api/yad2/ingest` ב-remax-bot (מפתח APP_INGEST_KEY ב-Script Properties).
payload: `{key, stream: private|agency, machine, scanFull, rows|delisted}`.
האפליקציה ממיינת: פרטי חדש → **נכס נולד** (upsert לפי מזהה יד2; פוש/השהיות/מי-פנה
דרך הלוגיקה הקיימת) · משרד אחר → **שת"פ** · שלושת סניפי רימקס פמילי → **נכסי המשרד**.

## החלטות אייל (30/08)
1. **נכסי המשרד עוברים לאוטומט** מהסריקה (מבטל את "ידני בינתיים" מ-24/08).
2. **הצינור הישן של נכס נולד נכבה** אחרי שהחדש מוכח (מעבר בחפיפה; הדדופ הקיים
   ב-newborn_listings — id:/ln:/ad: — בולע כפילויות).
3. דשבורד הפרויקט נשאר כלי נפרד וחי.
4. נכס נולד = מודעות **פרטיות** חדשות בלבד (מודעה חדשה של משרד אחר = שת"פ).
5. **"ירד מפרסום" לא מוחק** — הרשומה נשארת בתצוגה עם תווית "ירד מפרסום (תאריך)"
   בכל שלושת הזרמים (דורש שדה delisted_at + תווית UI).
6. מסחרי מחוץ לתחום.
7. רימקס פמילי = **שלושה** agency IDs (ידועים: 5625538, 5628636; השלישי — מהצ'אט השני).

## שלבים
**שלב א' (נבנה עכשיו):** `/v2/api/yad2/ingest` (מפתח YAD2_INGEST_KEY): private→newborn_listings
(source_key='id:'+_orderId — מתאחד עם הצינור הישן!), agency שאינו-שלנו→external_exclusives
(source_key='y2x:'+token; raw בסגנון getRaw_: street/dest/price/office/link/phone), delisted→
תווית raw.delisted_at (בלי מחיקה, בלי מיגרציית SQL — בתוך ה-jsonb). שורות 3 הסניפים שלנו:
נספרות ומוחזרות בתשובה (ourN) אך לא נכתבות — שלב ב'. סריקה חלקית: delisted מכובד רק אם
scanFull (השערים גם בצד הסורק). **שלב ב' (עיצוב נפרד):** נכסי המשרד לאוטומט + תוויות UI
"ירד מפרסום" במסכים + כיבוי הצינורות הישנים אחרי חפיפה.
